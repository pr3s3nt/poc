# I04-05 — AWS modules và xác minh độc lập

## Outcome và review

Packaged VPC/EKS/Aurora/ElastiCache ở release `v3-2026.10.13`, AWS provider
6.60.0, Terraform 1.9.8. EKS addon builds được pin; Connection/account/region
và stable state/identity/secret refs giữ nguyên. EKS public API nhận danh sách
IPv4 `/32` do PE/Admin cung cấp, không default mọi IP; private endpoint bật.

Review sửa immutable revision, addon service defaults, ACU min/max/increments,
node types và subnet CIDR collision. Người dùng chốt VPC sở hữu private network
dùng chung, trả privateSubnetIds cho Aurora/ElastiCache qua Resource References.
Hai database và hai cache hợp nhất về một VPC provider node. Consumer modules
không tạo subnet/route table; cleanup giữ VPC khi còn consumer. Không thêm
allocator/multiple VPC/peering hoặc migration tài nguyên v1.
