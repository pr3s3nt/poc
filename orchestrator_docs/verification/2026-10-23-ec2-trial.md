## Live execution

### Initial run: failed bootstrap, cleanup proven

The infrastructure apply created all eleven planned resources. Source builds
completed, but PostgreSQL initialization failed because root-only umask 077 had
also been applied to Git checkout. Executable source scripts became 0700;
non-root PostgreSQL could neither execute nor source its bind-mounted init file.
The same checkout mode also endangered the non-root backend entrypoint.

The apply failure hook triggered its detached supervisor. Terraform destroyed the
run using its original state. `absence.sh` independently verified exact EC2
termination and root-volume/ALB/listener/target-group/SG/key-pair/IAM role/policy/
profile absence. `native-absence-proven` and the native API receipt are retained
privately. No dependent retry started before this proof.

Fix `4a825b2` limits umask 022 to source checkout in both first installation and
release updates; private configuration/state/backup operations retain umask 077.
An isolated actual Git checkout reproduced old 0700 permissions and verified
0755 for both required executable assets under the fix. Terraform validation,
five mock security tests, shell syntax and docs checks passed after the fix.
